
## 1. Deployment und Service anwenden; der Dienst wählt Pods über Labels
$ kubernetes-validate -k 1.31 --strict app.yaml
OK: app.yaml passed for resource deployment/web
OK: app.yaml passed for resource service/web
$ k8ssim apply -f app.yaml
deployment.apps/web created
service/web created
$ k8ssim get svc
NAME  TYPE       CLUSTER-IP    PORT(S)
web   ClusterIP  10.96.139.68  80/TCP
$ k8ssim get endpoints
NAME  ENDPOINTS
web   10.244.3.148:8080,10.244.2.145:8080,10.244.3.136:8080

## 4. Fehler: Selector passt zu keinem Pod (Tippfehler im Label)
$ kubernetes-validate -k 1.31 --strict falsch.yaml
OK: falsch.yaml passed for resource service/falsch
$ k8ssim apply -f falsch.yaml
service/falsch created
$ k8ssim get endpoints
NAME    ENDPOINTS
falsch  <none>
web     10.244.3.136:8080
$ k8ssim curl falsch
curl: Connection refused (Service falsch hat keine Endpunkte)
Der Dienst existiert und ist gültig, hat aber keine Endpunkte: Die Prüfung des Schemas findet diesen Fehler nicht.
