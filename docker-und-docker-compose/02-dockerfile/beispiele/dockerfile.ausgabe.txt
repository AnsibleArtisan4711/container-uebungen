## 4. Schichten (history) und Anzahl der Dateisystemschichten

2: ENTRYPOINT ["cat"]

5: RUN /bin/sh -c echo "gebaut mit Stand $STAND" > /app/build.txt

7: WORKDIR /app
8: ENV APP_NAME=demo STAND=1
9: ARG STAND=1

## 5. Cache: unveränderter Bau, dann Datei geändert (Zustand je Schritt)
unverändert:
[2/4] WORKDIR /app: aus dem Cache
[3/4] COPY . /app: aus dem Cache
[4/4] RUN echo "gebaut mit Stand 1" > /app/build.txt: aus dem Cache
nach Änderung von version.txt:
[2/4] WORKDIR /app: aus dem Cache
[3/4] COPY . /app: neu gebaut
[4/4] RUN echo "gebaut mit Stand 1" > /app/build.txt: neu gebaut
